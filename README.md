# One Dark

[One Dark](https://github.com/atom/atom/tree/master/packages/one-dark-ui) theme for [Omarchy](https://omarchy.org/).

## Install

```bash
omarchy theme install https://github.com/joaopinto15/omarchy-one-dark-theme
```
